Q2「隨機抽一家」在官方文件上怎麼寫？業者可以指定嗎？

結論：官方寫的是食藥署派案／分派／指派，不是「隨機抽籤」；官方文件未提供業者指定受託機構的程序；派案依據未公開【查無】。
官方文件原文
QMS 申請須知 八(一)1 S07「食藥署收件後，派案至承辦人員(食藥署)或受託機構。」
QMS 申請須知 作業流程圖 S07食藥署欄「案件分派發文」→ 承辦人員或受託機構欄「受理、安排檢查」
QMS 常見問答 一、Q19 S06多廠屬同一品質系統併案時，「食品藥物管理署得指派同一受託評鑑機構安排檢查」
QMS 申請須知 八(六)2 S07「複評案件由原承辦人員或原受託機構辦理」
委託辦法 第17條 S03受託機構有應迴避或影響獨立公正之情事應通知；「中央主管機關得依前項通知，變更受託機構」
核發辦法 第8條 S02「前項取樣為無償，並隨機為之，醫療器材製造業者不得指定樣品」——「隨機」只用於產品取樣

怎麼理解：從業者角度，送件後由誰來查不是自己選的（與官方流程一致）；但官方沒有說是「隨機」，派案也可能直接由食藥署承辦人員辦理、不一定派給受託機構。食藥署依什麼原則派給哪一家（輪派、依產品別、依地區或其他），官方文件未揭露。

公正性設計（供參）：受託機構檢查人員若「現為受檢查醫療器材商諮詢輔導機構之從業人員」等情形，應自行迴避 S03。

Q5政府端的查廠機構可以核發 ISO 13485 證書嗎？

結論：以「食藥署受託機構」的身分，不行。這條流程的產出是食藥署的准予核定函文與「醫療器材製造許可」，不是 ISO 13485 證書。
  • 檢查合格「核發醫療器材製造許可」的是中央主管機關 S02；流程上受託機構「撰寫稽查報告」，食藥署「核發函文」S07。
  • 檢查標準是 QMS 準則（參照 ISO 13485:2016 訂定）S06；產出的「醫療器材品質管理系統準則稽查報告」僅核發正體中文版 S06S07。
  • 官方把兩者分開：我國業者可「檢附食藥署出具之…稽查報告，向…歐盟醫療器材公告機構申請品質管理系統驗證」S13——驗證要另外向驗證機構申請。

ISO 13485 證書由誰發？

  • 由第三方驗證機構核發，例如 BSI、SGS 皆自述提供 ISO 13485 驗證 S26S27。
  • TAF（財團法人全國認證基金會）只做「認證」不做「驗證」：「本會提供管理系統驗證機構認證(Accreditation)服務，不提供稽核/驗證(Audit/Certification)服務」S23。且 TAF 現行管理系統驗證機構認證領域（ISO 9001／14001／45001／22000／27001 系列／50001／46001）未列 ISO 13485 S23；某張 ISO 13485 證書由哪個認證機構背書，需看證書上的認證標誌（本次未逐張查證）。

這 4 家法人有沒有另外的驗證業務？

  • 商檢中心持有 TAF 管理系統驗證機構認證（MS020），但官網管理系統驗證項目列 ISO 9001／14001／45001／TOSHMS／22716／27001，未列 ISO 13485 S22S24。
  • 金屬中心持有 TAF 管理系統驗證機構認證（MS019）S24，但 TAF 該方案不含 ISO 13485 S23；金屬中心、工研院量測中心、塑膠中心是否另提供 ISO 13485 驗證【未逐一查證】。

Q6「醫材取證」＝ ISO 13485 嗎？台灣業者要拿哪些證照／許可？

結論：不等於。台灣法定要拿的是三層許可；ISO 13485 證書是自願性第三方驗證，不能取代食藥署的製造許可——國內製造者除公告免取得品項外，一律須檢查合格取得製造許可 S01S06；產品取得國外上市許可也不能取代 S06。

05建議跟馬哥確認的事

確認這 4 點，就能對齊兩邊資訊的時間點與指涉對象。

  1. 「三家」的第三家是哪一家？是工研院量測中心，還是台灣商品檢測驗證中心（舊名台灣電子檢驗中心）？這個資訊大約是哪一年聽到的？
  2. 「隨機抽一家」的出處：是食藥署說明、實際送件經驗，還是顧問轉述？實際送件時是否收到食藥署派案通知、通知上寫哪家機構？
  3. SGS、BSI 指的是哪一種身分：(a) 臺歐 TCP 合作的歐盟機構（BSI 現仍在 TCP III；SGS 只在 2021 年以前的 TCP II）；(b) 民間 ISO 13485 驗證；還是 (c) 其他角色？
  4. 「針對 ISO 13485 審查」指的是哪一件事：食藥署 QMS 檢查（依 QMS 準則，取得製造許可，強制）？還是民間 ISO 13485 驗證（自願，例如外銷客戶要求）？兩者是否都要做？
